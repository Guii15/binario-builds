MONTADOR DE PC - BINÁRIO TECNOLOGIA (versão React / Lovable)
============================================================

COMO RODAR LOCALMENTE
  1. npm install
  2. npm run dev
  3. abrir http://localhost:8080

ONDE ESTÁ O CÓDIGO PRINCIPAL
  src/routes/index.tsx   -> toda a lógica e o layout do montador
  src/styles.css         -> todos os estilos

FOTOS DOS PRODUTOS
  public/fotos/          -> fotos de exemplo (com timbrado da Binário)
  No código, cada peça tem um campo opcional "foto: /fotos/arquivo.jpg".
  Se a peça não tiver foto, o card mostra o ícone da categoria.
  Quando o extrator do WinThor rodar, gere os produtos com
  foto: "/fotos/<codigo>.jpg" e jogue as fotos (nomeadas pelo código)
  dentro de public/fotos/ — o resto funciona sozinho.

PENDÊNCIAS (ver README.md para o resto)
  - Confirmar os telefones dos vendedores e do T.I./Estoque no index.tsx
    (constantes VENDEDORES e CONTATOS_TI, lá no topo do arquivo).
  - Ligar o extrator do WinThor para trazer catálogo real.
  - Fotos: só 8 de exemplo aqui; o acervo completo é ~6000.

Este ZIP NÃO inclui node_modules (roda "npm install" para recriar).
